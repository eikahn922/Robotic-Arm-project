# CAD Models

CAD files are grouped by robot subsystem so the repository can grow without mixing unrelated components.

## Base

- [`base/Robot-Arm-Base-v1.SLDPRT`](base/Robot-Arm-Base-v1.SLDPRT) contains the first SolidWorks model of the structural base.

## Waist

- [`waist/Robot-Arm-Waist-v1.SLDPRT`](waist/Robot-Arm-Waist-v1.SLDPRT) contains the first SolidWorks model of the rotating waist component.

Future revisions should increment the version number while retaining older versions when they document meaningful design changes.
