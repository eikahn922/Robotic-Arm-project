# CAD Models

CAD files are grouped by robot subsystem so the repository can grow without mixing unrelated components.

## Base

- [`base/Robot-Arm-Base-v1.SLDPRT`](base/Robot-Arm-Base-v1.SLDPRT) contains the first SolidWorks model of the structural base.

## Link

- [`link/Robot-Arm-Link-1.SLDPRT`](link/Robot-Arm-Link-1.SLDPRT) contains the first structural arm link.
- [`link/Robot-Arm-Link-2.SLDPRT`](link/Robot-Arm-Link-2.SLDPRT) contains the second structural arm link.
- [`link/Robot-Arm-Link-3.SLDPRT`](link/Robot-Arm-Link-3.SLDPRT) contains the third structural arm link.

## Servo

- [`servo/MG996R_servo.SLDPRT`](servo/MG996R_servo.SLDPRT) contains the MG996R servo model.
- [`servo/SG90 - Micro Servo 9g - Tower Pro.1.SLDPRT`](servo/SG90%20-%20Micro%20Servo%209g%20-%20Tower%20Pro.1.SLDPRT) contains the Tower Pro SG90 micro-servo model.

## Waist

- [`waist/Robot-Arm-Waist-v1.SLDPRT`](waist/Robot-Arm-Waist-v1.SLDPRT) contains the first SolidWorks model of the rotating waist component.

Future revisions should increment the version number while retaining older versions when they document meaningful design changes.
